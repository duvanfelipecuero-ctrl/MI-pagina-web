# Taller de Fundamentos Web: HTML, CSS y JavaScript

---

### 1. ¿Qué es HTML y cuál es su función en la web?
Es el lenguaje de marcado estándar que define la estructura y el contenido de una página web (textos, imágenes, enlaces).

---

### 2. ¿Qué es una etiqueta HTML y cuáles son las más comunes?
Es un código delimitado por `<>` que indica al navegador cómo debe mostrar el contenido. 

**Etiquetas comunes:**
* `<h1>` - `<h6>` (Títulos)
* `<p>` (Párrafos)
* `<a>` (Enlaces)
* `<img>` (Imágenes)
* `<div>` (Contenedores)
* `<button>` (Botón)

---

### 3. ¿Qué es un atributo de una etiqueta HTML y cuáles son los más comunes?
Es un valor dentro de la etiqueta de apertura que añade información o configuración adicional.

**Atributos comunes:**
* `src` (Fuente del archivo)
* `href` (Destino del enlace)
* `id` (Identificador único)
* `class` (Clase para estilos)
* `alt` (Texto alternativo)

---

### 4. ¿Qué es CSS y cómo se utiliza para el diseño web?
Es el lenguaje utilizado para aplicar diseño y presentación visual (colores, fuentes, márgenes) a la estructura HTML.

---

### 5. ¿Qué es una propiedad en CSS y cuáles son las más comunes?
Es la característica estética concreta de un elemento que se desea modificar.

**Propiedades comunes:** `color`, `background-color`, `font-size`, `text-align`, `margin` y `padding`.

---

### 6. ¿Qué es un selector en CSS y qué tipos existen?
Es el patrón que indica a qué elementos del HTML se les aplicarán los estilos.

**Tipos principales:**
* **Universal:** `*`
* **Etiqueta:** `p`
* **Clase:** `.clase`
* **ID:** `#id`
* **Atributo:** `[tipo]`

---

### 7. ¿Qué es JavaScript y cómo añade interactividad a las páginas web?
Es un lenguaje de programación que permite modificar el contenido en tiempo real y responder a las acciones del usuario (clics, eventos, datos).

---

### 8. ¿Cuáles son los tipos de datos primitivos en JavaScript?
`String`, `Number`, `Boolean`, `Undefined`, `Null`, `Symbol` y `BigInt`.

---

### 9. ¿Cómo funcionan las estructuras de control de flujo en JavaScript?
* **`if / else`:** Evalúan condiciones lógicas para decidir qué bloque de código ejecutar.
* **`switch`:** Selecciona un bloque de código según la coincidencia con distintos casos.
* **Bucles (`for`, `while`):** Repiten un bloque de código mientras se cumple una condición.

---

### 10. ¿Por qué es importante usar nombres significativos para variables y métodos?
Facilita la lectura, comprensión y mantenimiento del código por parte de cualquier desarrollador.

---

### 11. ¿Qué es una variable de entorno y por qué es importante?
Es un valor configurado fuera del código fuente que sirve para proteger credenciales sensibles (claves API, contraseñas) y cambiar valores entre el entorno de desarrollo y producción.

---

### 12. ¿Qué son las herramientas de desarrollo de Chrome y cómo se accede a ellas?
Son utilidades integradas en el navegador para inspeccionar HTML/CSS, depurar código JavaScript y monitorear el rendimiento. Se accede presionando `F12` o clic derecho y **Inspeccionar**.

---

### 13. ¿Qué es el DOM (Document Object Model) y cómo interactúa JavaScript con él?
Es la representación en forma de árbol jerárquico de la estructura del documento HTML. JavaScript interactúa con él para seleccionar, modificar, agregar o eliminar elementos de la página dinámicamente.

---

### 14. ¿Qué son los eventos en JavaScript y cómo se utilizan?
Son acciones o sucesos que ocurren en el navegador (como un clic del mouse, presionar una tecla o el envío de un formulario). Se utilizan mediante *event listeners* para ejecutar código cuando el usuario realiza dicha acción.

---

### 15. ¿Cuál es la diferencia entre un lenguaje de marcado, de estilo y de programación en el desarrollo web?
* **HTML (Lenguaje de marcado):** Define el esqueleto y la estructura del contenido.
* **CSS (Lenguaje de estilos):** Define la apariencia, colores y diseño visual.
* **JavaScript (Lenguaje de programación):** Define la lógica, el comportamiento dinámico y la interactividad.
